# App Icons

Open `Open Generate App Icons` from the Images category. The `Icon preset` select offers macOS (default), Favicon, iOS, and Android. The run button is `Icons`. Only the first selected file is used.

Expect square PNGs for the selected preset only, stretched to size with no padding:
- macOS: `<stem>-macos-icon-{16,32,128,256,512,1024}.png` plus `<stem>-macos-icon.icns`.
- Favicon: `<stem>-favicon-{16,32,48,64,128,256}.png`. The detail says an ICO container is unavailable.
- iOS: `-ios-icon-{20,29,40,60,76,83,1024}.png`.
- Android: `-android-icon-{48,72,96,144,192,512}.png`.
