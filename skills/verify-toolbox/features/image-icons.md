# Generate App Icons

Open `Generate App Icons`, select an image, choose an `Icon preset`, and press `Icons`. With the macOS preset expect `macOS PNG and ICNS icon set saved.` and outputs `{stem}-macos-icon-{16,32,128,256,512,1024}.png` plus `{stem}-macos-icon.icns`. Verify each PNG has its stated square size and the source is unchanged.
