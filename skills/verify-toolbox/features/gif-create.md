# Create GIF

Open `Open Create GIF` from the Images category. Controls are `Frame delay (ms)` (default 100) and `Loop animation` (default on). The run button is `GIF Maker`.

Select two or more images and run it. Expect `<first-stem>-animated.gif` beside the first input, with one frame per image at the chosen delay, and the detail `GIF saved`. Images of different sizes are accepted; the canvas takes the largest width and height. One image gives a one-frame GIF. Inputs stay unchanged.
