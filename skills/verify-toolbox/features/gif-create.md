# Create GIF

Open `Create GIF`, select two or more same-sized images (add each extra file with a foreground click on the dropzone icon), set `Frame delay (ms)` (default 100) and the `Loop animation` checkbox, and press `GIF Maker`. Expect one `GIF saved` result for the whole batch and a `{first stem}-animated.gif` beside the first input. Verify the GIF has one frame per input and the inputs are unchanged.
