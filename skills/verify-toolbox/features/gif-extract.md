# Extract GIF Frames

Open `Extract GIF Frames` (blurb: `Split an animated GIF into individual frames.`), select an animated GIF, and press `Frames`. Expect `GIF frames saved` and outputs `{stem}-frame-1.png` … `{stem}-frame-N.png` plus `{stem}-frame-timing.json`. Verify one PNG per frame at the source dimensions, a timing entry per frame, and an unchanged source GIF.
