# Brag Plan: Toolbox

## What is this app?
Toolbox is a cross-platform desktop app for private, local-first PDF, document, and image utilities.

## The angle
Treat privacy as the product feature: show a real desktop file workflow, then make the on-device boundary the payoff.

## Hook (first 2-3 seconds)
“Your files stay yours.” The actual Toolbox mark and three file-type tiles give the line a product context immediately.

## Key moments
- The current Toolbox tool library: PDF, image, and document utilities in a persistent desktop workspace.
- The current Edit PDF screen, with a fictional sample.pdf placeholder selected for the demo.
- Three clear steps: select a file, make an edit, save a separate copy.

## Outro / punchline
“Private by default. Files stay on this device.” Land the Toolbox wordmark on the 17.02s music cue.

## User flow worth showing
Choose or drop a local file → use a PDF edit action such as text, note, highlight, or shape → save a new output while leaving the original unchanged. The on-screen sample.pdf name is a fictional placeholder; no file is processed for this video.

## Tone
- Preset: polished
- Creative direction: quiet desktop product film with a local-first heart
- Interpretation: restrained motion, honest product language, and enough time to read each line.

## Format: landscape — 1920x1080
## Duration: 20.2 seconds

## Visual identity
- Background: #171717
- Surface: #202020
- Accent: #60a5fa
- Text: #ededed
- Muted text: #999999
- Display and body font: system UI sans-serif
- Strongest visual element: the current Toolbox command center and Edit PDF workspace, captured from the local development UI.

## Share copy (draft)
Toolbox is a desktop toolkit for PDF, document, and image work. Files are processed on-device and never uploaded.

## Audio direction
- Role: warm, understated momentum under a privacy-focused product film
- Music: “Happy Beats & Business Moves Vol. 1” by Sascha Ende, sourced from ende.app under CC BY 4.0
- Music treatment: short local excerpt; gentle fade-in and fade-out are baked into the local audio asset; restrained level
- Music cue guidance: bundled cue preset is 120.19 BPM. Major brand reveal at 17.02s; workflow steps align to 9.02s, 10.02s, and 11.02s.
- Audio-reactive treatment: subtle bass response on the screenshot frame’s blue rim light; no text scaling or visualizer graphics
- SFX posture: sparse; quiet UI clicks for the three step reveals and one soft reveal accent for the wordmark
- Restraint rule: sound supports the interface and privacy message; it never competes with text.

“Private by default. Files stay on this device.” The Toolbox wordmark lands at 17.02s and holds through the final frame.
