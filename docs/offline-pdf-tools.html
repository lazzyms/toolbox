Offline PDF tools

The PDF tools you use online,
without the upload.

Toolbox is a free desktop app with the everyday tasks of online PDF and image sites. Your files are processed on your computer.

Download for macOS

Free for macOS and Windows · Microsoft Store · No upload, no account

How to offline PDF tools with Toolbox

  1. Download Toolbox for macOS, or get it from the Microsoft Store on Windows.
  2. Pick a tool: merge, split, compress, sign, unlock, convert or resize.
  3. Add your files. There is no account, upload or daily limit.
  4. Toolbox saves the results next to your originals.

Questions

Is Toolbox related to iLovePDF or Smallpdf?

No. Toolbox is an independent, open source project. Those names belong to their owners.

How is it different from online PDF sites?

Toolbox runs on your computer, so it never uploads your files and needs no account.

Is it free?

Toolbox runs on macOS (Apple silicon) and Windows. The Windows app comes from the Microsoft Store. It is free and MIT licensed.

Does it change my original files?

No. Toolbox saves a new file beside the original and never overwrites it.
