Privacy Policy

Last updated: October 22, 2026

This policy covers the Toolbox desktop application for macOS and Windows and this website. Toolbox is published by Maulik Sompura (“we”). It describes what Toolbox sends over the network, why, and the choices you have.

Your files stay on your device

Every Toolbox tool, including OCR and document conversion, runs on your computer. Toolbox never uploads the files you open, and never sends file names, file paths, file contents or the results of a run. Toolbox has no accounts and no sign-in.

What each build sends

Microsoft Store build

The Windows app installed from the Microsoft Store sends no usage data and makes no feature-flag or update requests. The Microsoft Store installs updates. Microsoft handles your download, purchase and update information under the Microsoft Privacy Statement.

GitHub release builds

The macOS and Windows installers published on GitHub make these requests:

  • Usage counts. Toolbox sends a first_install event the first time it runs and an app_opened event each time it starts. Each event carries a random install ID created on your device, the label tauri, and the time. The events go to PostHog, our analytics provider, in its United States region.
  • Tool availability. Each time Toolbox starts, it sends the same random install ID to PostHog to learn which tools are turned on for your platform. This lets us switch off a tool that is not working. If the request fails, Toolbox uses the tools built into that version.
  • Update checks. When you choose Check now in Settings, Toolbox reads the latest version information from GitHub. If you agree to install an update, Toolbox downloads it from GitHub.

As with any internet request, PostHog and GitHub receive your IP address. Toolbox asks PostHog not to look up your location from it. The install ID is not linked to your name, email address or any account.

How to turn it off

Turn off Share anonymous usage counts in Settings > Privacy. Toolbox then stops sending usage counts and tool-availability requests, and uses the tools built into that version. Update checks happen only when you ask for one. Development builds never send usage data.

Why we use this data

We use these counts to understand how many people install and open Toolbox, and to turn off a broken tool quickly. Where the GDPR or a similar law applies, we rely on our legitimate interest in keeping Toolbox working and learning whether it is used. You can object at any time by turning off the setting above. We do not use this data for advertising, we do not sell or share it for cross-context behavioral advertising, and we do not combine it with other data about you.

Who receives it

  • PostHog processes the usage counts and tool-availability requests for us in the United States.
  • GitHub serves update information, downloads and this website.
  • Microsoft runs the Microsoft Store.

Each provider handles data under its own privacy policy. If you are outside the United States, your data may be processed there.

How long we keep it and how it is protected

Usage events stay in PostHog under the data retention settings of the Toolbox project and are used only in aggregate. All requests use HTTPS. The install ID and your choices stay in the app’s local storage on your device until you uninstall Toolbox or clear its data.

Your rights

Depending on where you live, including under the GDPR, the California Consumer Privacy Act and India’s Digital Personal Data Protection Act, you may have the right to know what data we hold about you, to have it corrected or deleted, and to object to its use. Because Toolbox data is tied only to a random install ID, turning off the setting above stops all collection. To make a request, open an issue on the Toolbox GitHub issue tracker. Issues are public, so do not include personal details. We will tell you how to continue privately. You may also complain to your local data protection authority.

Children

Toolbox is a general-purpose file tool. It is not directed at children, and we do not knowingly collect personal data from children.

Website

Pages with the theme switcher save your light or dark choice in this browser’s local storage. That preference stays in this browser and is not sent to Toolbox. The website loads no analytics or advertising scripts and sets no tracking cookies. GitHub Pages hosts the site and may log requests as described in GitHub’s privacy statement.

Open-source components

Toolbox includes open-source components. Their licenses are listed in the third-party notices and in the app under Settings > About.

Changes and contact

We update this policy when Toolbox’s data practices change, and we change the date at the top. Questions can be raised through the Toolbox GitHub issue tracker.
