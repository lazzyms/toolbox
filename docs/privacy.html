Privacy Policy

Last updated: September 23, 2026

Website theme preference

Pages with the theme switcher save your explicit light or dark choice in this browser's local storage. That preference stays in this browser and is not sent to Toolbox. The website code does not load analytics or advertising scripts, and does not set tracking cookies.

Files and content

Toolbox is a local desktop application. Files you select are processed on your device and are not uploaded to Toolbox servers. Toolbox does not require an account and does not collect filenames, file paths, or file contents through its file-processing features.

Anonymous analytics

Release builds may use Firebase Analytics to measure installation and app-open events. These events include an anonymous app instance identifier and a platform label such as macOS or Windows. They do not include filenames, paths, file contents, or the results of file operations. Development builds keep this analytics integration inactive.

Update checks

Release builds may check the configured update endpoint for application updates. This request may include standard network information required to make the request, such as your IP address, which is handled by the hosting provider. Toolbox does not use update checks to upload your files.

Third-party services

Firebase Analytics is provided by Google and is subject to Google’s Privacy Policy. The Microsoft Store and GitHub may process information when you download or update Toolbox through their services.

Changes and contact

This policy may be updated when Toolbox’s data practices change. Questions or requests can be raised through the Toolbox GitHub issue tracker.
