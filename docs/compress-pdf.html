How to compress PDF with Toolbox

  1. Open Toolbox and choose Compress PDF.
  2. Add one or more PDF files.
  3. Start the run.
  4. Toolbox saves a compressed copy next to each original.

Questions

How much smaller will my PDF get?

It depends on the file. Toolbox compresses the PDF stream data. Files that are already compressed may shrink very little.

Can I compress several PDFs at once?

Yes. Add as many PDFs as you like. If one file fails, the others still finish.

Is my PDF uploaded?

No. Toolbox is a desktop app, so it reads and writes the file on your own computer. It never uploads your files.
