Sign PDF

Sign a PDF
without an upload.

Add a typed name, or a PNG or JPEG image of your signature, to one or more pages of a PDF.

Download for macOSGet it from Microsoft Store

Free · No upload, no account

How to sign PDF with Toolbox

  1. Open Toolbox and choose Sign PDF.
  2. Add the PDF.
  3. Type your name or choose a PNG or JPEG signature image, then pick the pages.
  4. Toolbox saves a signed copy next to the original.

Questions

Is this a digital certificate signature?

No. Sign PDF places a visible signature mark on the page. It is not a cryptographic signature.

Is my document uploaded?

No. Toolbox is a desktop app, so it reads and writes the file on your own computer. It never uploads your files.

Does it change the original file?

No. Toolbox saves a new file beside the original and never overwrites it.
