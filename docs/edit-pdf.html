    How to edit PDF with Toolbox

    1. Open Toolbox and choose Edit PDF.
    2. Add the PDF.
    3. Add text, highlights, rectangles or notes to the pages you select.
    4. Toolbox saves an edited copy next to the original.

    Questions

    Can I change the existing text in a PDF?

    No. Edit PDF adds new text, highlights, shapes and notes on top of the page. It does not rewrite text that is already there.

    Can I add page numbers or a watermark?

    Yes. Use Add PDF Page Numbers or Watermark PDF.

    Is my PDF uploaded?

    No. Toolbox is a desktop app, so it reads and writes the file on your own computer. It never uploads your files.
