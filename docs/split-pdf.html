Split PDF

Split a PDF
into the parts you need.

Break a PDF into single pages, page ranges or fixed-size chunks. You can also extract or remove selected pages.

Download for macOS

Free for macOS and Windows · Microsoft Store · No upload, no account

How to split PDF with Toolbox

  1. Open Toolbox and choose Split PDF.
  2. Add the PDF.
  3. Choose single pages, ranges such as 1-3, 7, or a fixed chunk size.
  4. Toolbox saves the new PDFs next to the original.

Questions

Can I pull out only a few pages?

Yes. Use Extract PDF Pages to save selected pages as a new PDF, or Remove PDF Pages to drop the pages you do not need.

Is my PDF uploaded?

No. Toolbox is a desktop app, so it reads and writes the file on your own computer. It never uploads your files.

Does it change the original file?

No. Toolbox saves a new file beside the original and never overwrites it.
