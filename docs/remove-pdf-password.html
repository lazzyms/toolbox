Remove a PDF password,
without uploading it.

Enter the password you already know, and Toolbox saves an unlocked copy of the PDF or Office file. Nothing is uploaded.

Free for macOS and Windows · Microsoft Store · No upload, no account

How to remove PDF password with Toolbox

  1. Open Toolbox and choose Remove Password.
  2. Add one or more PDF, DOC, DOCX, XLS, XLSX, PPT or PPTX files.
  3. Type the password you use to open each file.
  4. Toolbox saves an unlocked copy next to each original.

Questions

Can Toolbox unlock a PDF if I forgot the password?

No. Remove Password needs the password you use to open the file. It cannot recover, guess or bypass a password.

Which files can I unlock?

PDF files and password protected Word, Excel and PowerPoint files: DOC, DOCX, XLS, XLSX, PPT and PPTX. Unsupported encryption returns an error for that file only.

Is my PDF uploaded to a server?

No. Toolbox is a desktop app, so it reads and writes the file on your own computer. It never uploads your files.

Does it change the original file?

No. Toolbox saves a new file beside the original and never overwrites it.
